مِهني | أدوات مساحية — نسخة أولية 0.1

المحتويات:
- index.html: التطبيق كامل في ملف واحد.
- manifest.json و sw.js: ملفات اختيارية لتجهيزه كتطبيق ويب قابل للتثبيت (PWA).
- README.txt: تعليمات التشغيل.

تشغيل سريع:
1) افتح index.html في Chrome أو أي متصفح حديث.
2) حساب المساحة وتقسيم الأراضي والمسافة والسمت والميزانية تعمل محليًا.
3) تحويل الإحداثيات يحتاج إنترنت لتحميل مكتبة proj4 من jsDelivr.
4) لتثبيت التطبيق على الهاتف، انشر المجلد على استضافة HTTPS مثل GitHub Pages. فتح الملف مباشرة لا يكفي عادة لتفعيل PWA.
5) راجع أن الإحداثيات المستوية من نظام واحد ووحدة واحدة. التحويلات تحتاج اختيار UTM zone وhemisphere الصحيحين.
