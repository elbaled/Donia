# مِهني | أدوات مساحية

نسخة الويب التجريبية 0.2.0، جاهزة للرفع إلى GitHub Pages.

## الملفات
- `index.html`: التطبيق.
- `manifest.json`: بيانات تثبيت التطبيق كـ PWA.
- `sw.js`: التخزين المؤقت والعمل الأساسي دون اتصال.
- `icon.svg`: أيقونة التطبيق.
- `TEST_RESULTS.txt`: أمثلة اختبارات الحسابات الأولية وحدودها.

## نشر التطبيق باستخدام GitHub Pages من الهاتف أو الكمبيوتر
1. أنشئ مستودعًا جديدًا (Repository) على GitHub، مثل `mihani-survey-tools`.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع، وليس ملف ZIP نفسه.
3. افتح `Settings` ثم `Pages`.
4. تحت `Build and deployment` اختر `Deploy from a branch`.
5. اختر الفرع `main` والمجلد `/(root)` ثم اضغط `Save`.
6. انتظر حتى يظهر رابط GitHub Pages، ثم افتحه في Chrome.
7. لتثبيته على Android، افتح قائمة Chrome واختر `Install app` أو `Add to Home screen` إذا ظهر الخيار.

## ملاحظات
- احتفظ بنسخة احتياطية قبل أي تعديل.
- التخزين في هذه النسخة محلي داخل المتصفح؛ لا توجد مزامنة Firebase بين الأجهزة.
- بعض تحويلات الإحداثيات تعتمد على مكتبة تُحمّل عبر الإنترنت.
- أدوات GIS والاستشعار عن بُعد أولية وليست بديلًا عن برامج متخصصة أو مراجعة مساحية.
- هذه الملفات تنشر نسخة ويب/PWA، وليست ملف APK مستقلًا.
