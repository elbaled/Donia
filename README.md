# GeoPoint Professional v0.6.0

تطبيق ويب عربي/إنجليزي لأدوات المساحة والجيوماتكس.

## أدوات النسخة
- حساب مساحة مضلع من إحداثيات مستوية ورسمه تخطيطيًا.
- قياس الأرض بدون إحداثيات: مستطيل، مربع، مثلث، شبه منحرف، دائرة وأرض غير منتظمة بتجميع مساحات مثلثات.
- تحويل الفدان والقيراط والسهم إلى متر مربع والعكس، وجمع وطرح المساحات.
- تقسيم الأراضي، تحويل الإحداثيات، المسافة والسمت، الميزانية، الترافيرس، دفتر الميزانية، الطرق والكميات، GIS والاستشعار عن بعد، وإدارة المشروعات.

## النشر على GitHub Pages
ارفع محتويات هذا المجلد إلى جذر المستودع `elbaled/Donia` مع الاحتفاظ بنسخة احتياطية من الملفات القديمة.

## تنبيهات
- فدان مصر = 4200 م² في هذا الإصدار؛ راجع تعريفات الوحدات المحلية قبل الاستخدام الرسمي.
- القياس غير المنتظم بتجميع مثلثات يتطلب قواعد وارتفاعات عمودية صحيحة، أو بيانات هندسية كافية.
- الأداة مساعدة للحسابات الأولية ولا تحل محل مراجعة مسّاح مختص في تحديد الملكيات.
