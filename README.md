# GeoPoint PRO — GitHub Pages

واجهة عربية متجاوبة تركز على أربعة أقسام فقط: قياس الأرض، الكميات، الوصول إلى نقطة، والتسعير.

## النشر
1. خذ نسخة احتياطية من ملفات الموقع الحالي.
2. ارفع `index.html` و`manifest.json` و`icon.svg` و`sw.js` إلى جذر مستودع GitHub Pages.
3. افتح الموقع ثم حدّثه تحديثًا قويًا/امسح بيانات الموقع إذا ظهرت نسخة مخزنة قديمة.

## ما تتضمنه النسخة
- إدخال إحداثيات الرؤوس، رسم المضلع، حساب المساحة والمحيط، وحساب أطوال الأضلاع.
- بيانات المشروع والمهندس والمالك والتاريخ وملاحظات القطعة.
- أربعة حدود/جيران وتفاصيل إضافية، وتقرير HTML يمكن طباعته أو حفظه PDF.
- تقسيم مستطيل متساوٍ إلى صفوف وأعمدة مع رسم تخطيطي.
- حفظ المشروعات محليًا في المتصفح وتصدير/استيراد نسخة JSON.
- حسابات حجم أساسية، مسافة وسمت، ومقايسة سعرية.

## ملاحظات هندسية
- الحساب من إحداثيات الرؤوس يستخدم صيغة الحذاء (Shoelace). أدخل الرؤوس بالتتابع حول حدود المضلع، وتأكد من عدم تقاطع الأضلاع.
- لا يمكن تحديد مساحة كل مضلع غير منتظم من أطوال أضلاعه وحدها في كل الحالات؛ قد يلزم قطر أو ارتفاع أو زوايا أو إحداثيات إضافية. هذه النسخة تحسب بدقة من إحداثيات الرؤوس ولا تستنتج شكلًا غير محدد من أطوال فقط.
- التقسيم الحالي مخصص لمستطيل منتظم وللتخطيط المبدئي فقط، ولا يطبق اشتراطات التنظيم أو الارتدادات أو الطرق.
- الحفظ محلي على نفس المتصفح والجهاز؛ استخدم النسخة الاحتياطية لنقل المشاريع.
- هذه أداة مساعدة ولا تغني عن المراجعة الميدانية والاعتماد بواسطة مهندس مختص.
