# GeoPoint — Four Tools Edition

نسخة ويب عربية/إنجليزية تركز فقط على أربعة أقسام:
1. قياس الأرض بالإحداثيات أو تقسيمها إلى مثلثات وحساب مساحاتها ورسم مضلع الإحداثيات.
2. حساب الكميات الأساسية من الطول والعرض والعمق.
3. حساب المسافة والسمت وفروق الإحداثيات إلى نقطة مستهدفة.
4. جدول التسعير مع حفظ محلي وتصدير CSV.

## النشر على GitHub Pages
1. فك ضغط ملف ZIP.
2. افتح مجلد `GeoPoint_GitHub_Files` وانسخ الملفات الأربعة الأساسية (`index.html`, `manifest.json`, `sw.js`, `icon.svg`) إلى جذر مستودع `Donia` مع استبدال الملفات القديمة.
3. اعمل Commit changes وانتظر تحديث GitHub Pages.

## ملاحظات مساحية
- المساحة بالإحداثيات تعتمد على صيغة الحذاء (Shoelace) وتفترض أن جميع الإحداثيات مترية وفي نظام واحد.
- حساب المثلثات يستخدم صيغة هيرون؛ يجب تقسيم الأرض إلى مثلثات تغطيها بالكامل بلا تداخل.
- تحويل القيراط المعروض افتراضيًا على أساس 175 م² للقيراط، وقد تختلف التعريفات المحلية؛ عدّل القيمة إذا كانت وحدتك المحلية مختلفة.
- حساب الكميات حاليًا صيغة هندسية أساسية، وليس بديلًا عن حساب المقاطع المتغيرة أو اعتماد المهندس.
- التسعير محفوظ على الجهاز والمتصفح فقط، وليس قاعدة بيانات سحابية.
